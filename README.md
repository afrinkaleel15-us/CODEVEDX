# E-Commerce Performance Analysis Using SQL

## Project Overview
This project analyzes e-commerce sales data using MySQL to understand business performance, product sales, customer purchasing behavior, payment preferences, and regional revenue.

## Objectives
- Calculate total sales revenue and orders.
- Identify best-selling products.
- Analyze category-wise revenue.
- Study monthly sales performance.
- Identify top customers.
- Analyze payment methods.
- Compare regional sales performance.

## Tools Used
- MySQL
- MySQL Workbench
- SQL

## Dataset
The dataset contains 16 sample order records with the following columns:
- Order ID
- Order Date
- Customer Name
- Product Name
- Category
- Quantity
- Price
- Payment Method
- Region

## SQL Analysis Performed
1. Total Revenue
2. Total Orders
3. Best-Selling Products
4. Category-wise Revenue
5. Monthly Sales Performance
6. Top Customers by Revenue
7. Payment Method Analysis
8. Region-wise Sales Performance

## Conclusion
This project demonstrates how SQL can be used to analyze e-commerce data and generate useful insights about sales, customers, products, and business performance.
